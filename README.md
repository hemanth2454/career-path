## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/hemanth2454/career-path.git
```

### 2. Navigate to the project

```bash
cd career-path
```

### 3. Install dependencies

Install dependencies in the client and server directories according to their package.json files.

### 4. Configure environment variables

Create the required local environment configuration files using the variable names documented in the project.

Never commit private credentials.

### 5. Run the application

Follow the frontend and backend start commands defined in their respective package.json files.
